# camera.ui

[![npm](https://img.shields.io/npm/v/camera.ui?label=npm&logo=npm)](https://www.npmjs.com/package/camera.ui)

The launcher of camera.ui, the local-first camera and NVR platform. It installs the camera.ui server, keeps it up to date and runs it as a system service.

```sh
sudo npm install -g camera.ui
sudo cameraui install --user cameraui
```

The [Linux installation guide](https://docs.cameraui.com/install/linux) covers the details. The desktop app for macOS, Windows and Linux, the Docker images and the apps are at [cameraui.com/download](https://cameraui.com/download).
