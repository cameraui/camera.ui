# @camera.ui/server

The server of camera.ui, the local-first camera and NVR platform. It is not installed on its own: the desktop app, the Docker image, the Home Assistant app and the [`camera.ui`](https://www.npmjs.com/package/camera.ui) launcher install and update it. See the [installation guide](https://docs.cameraui.com/install/).
